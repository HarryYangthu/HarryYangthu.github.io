Research / Open source

MARS

Multi-Agent Research System
面向研究任务的多 Agent 工作台。

查看 GitHub ↗架构文档 ↗

研究过程也需要被组织。

MARS 将研究问题组织为方案、实验计划、代码规格、执行日志和报告，并保留记忆与评测记录，让研究过程可以回看和检查。

项目关注的三个方面

  • 多 Agent 协作：用专业化 Agent 组织不同阶段的研究工作。
  • 结构化产物：通过明确的产物格式衔接方案、实验和执行。
  • 记忆与评测：沉淀过程记录，并通过评测检查产物。

进一步了解

代码、运行说明与当前开发状态以公开仓库为准。此处为项目概览，详细案例与实验结果后续补充。

Knowledge / Open source

The Best AI Guide

面向学习和工程实践的 AI 知识库。

进入知识库 ↗

理解机制，然后亲手验证。

每个主题先解释机制，再给公式、算例和实现，最后用实验观察它何时有效、何时失败。

知识与项目相互连接

  • 模型基础：数学、机器学习、Attention 与 KV Cache。
  • Agent 工程：工具、上下文、记忆、工作流与评测。
  • 动手实验：Mini Agent、RAG 实验室与领域资料研究助手。

各章节的完成与验证状态以知识库内的标注为准。
