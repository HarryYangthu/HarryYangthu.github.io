Research / Open source

MARS

Multi-Agent Research System
A multi-agent workbench for research tasks.

View on GitHub ↗Architecture ↗

Organizing the Research Process

MARS organizes research questions into proposals, experiment plans, code specifications, execution logs, and reports. Memory and evaluation records make the process traceable and reviewable.

Three Areas of Focus

  • Multi-agent collaboration: Specialized agents support different stages of the research process.
  • Structured outputs: Defined output formats connect proposals, experiments, and execution.
  • Memory and evaluation: Preserve process records and evaluate the resulting outputs.

Learn More

See the public repository for code, setup instructions, and current development status. Detailed case studies and experimental results will be added here.
