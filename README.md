# Harry Young — Personal Website

个人网站第一版框架：项目、研究、写作与关于我。

## 页面

- 首页 `#home`
- 作品集 `#projects`
- 论文 `#research`（待补充）
- 博客 `#writing`（含公开学习资料入口）
- 关于 `#about`（个人简介与简历待补充）
- MARS 项目 `#project-mars`
- The Best AI Guide 项目 `#project-guide`

## 本地预览

直接在浏览器打开 `index.html`。无需安装依赖、构建或服务器。

## 发布与维护

GitHub Pages 从 `main` 分支根目录发布，提交页面修改后自动更新。
所有页面内容、CSS 和交互脚本位于 `index.html`；配色集中在 CSS 的 `:root`。

项目概览来自公开仓库说明。论文、简历、实验指标和个人定位尚未填入。
此版采用 hash 导航，支持直接打开文件及 Pages 深链接。正式内容扩展时可迁移为独立静态页面或 Astro/MDX，同时继续使用 GitHub Pages。
